# Source provenance

The initial bot source and 48 tests were exported from `tools/mooncake-bot/` in
`stmatengss/Mooncake` at commit `85514fe9b66627be56c13ed29e400d1d06ab9c69`
on 2026-10-29 (Asia/Shanghai), after PR #34 was merged. The implementation commits
were `0013fc76528e4a20e000b3157466cb964e2c38b5` and
`1c82b007716209af329840dfb48c82582fbab5a4`.

- Source: https://github.com/stmatengss/Mooncake/tree/85514fe9b66627be56c13ed29e400d1d06ab9c69/tools/mooncake-bot
- Design: https://github.com/stmatengss/Mooncake/issues/33
- Implementation: https://github.com/stmatengss/Mooncake/pull/34

This is a snapshot export of tracked source, example configuration and tests.
Runtime configuration, keys, provider credentials, queues, logs and evaluation
artifacts were excluded. The Mooncake Apache-2.0 license is preserved in
`LICENSE-APACHE`. The private LightSeek dispatcher was not copied.

The Python package and CLI remain `mooncake-bot` for existing deployment
compatibility. The GitHub App stays `stmatengss-mooncake-bot`; no second App or
additional repository installation is needed to maintain this source repository.

Future changes are maintained in `stmatengss/stmatengss-Mooncake-bot`.
AI assistance: Codex prepared and tested the export; the runtime model backend
is Kimi Code. Human line-by-line review is not attested by this provenance note.
